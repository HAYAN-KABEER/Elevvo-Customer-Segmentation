# 🧩 Customer Segmentation using RFM Analysis & KMeans Clustering  

This project explores **customer behavior analytics** on a real-world sales dataset. Using the **RFM (Recency, Frequency, Monetary)** model, I segmented customers into meaningful groups and suggested data-driven marketing strategies. Additionally, I applied **KMeans clustering** to compare unsupervised segmentation results.  

---

## 📌 Project Overview  
The goal of this project was to understand customer purchasing patterns and create actionable segments for marketing campaigns. Businesses can leverage such insights to **retain loyal customers, re-engage inactive ones, and maximize revenue**.  

---

## ⚙️ Workflow  

1. **Data Cleaning 🧹**  
   - Handled missing values, duplicates, and returns.  
   - Ensured transactional accuracy.  

2. **Feature Engineering ⚙️**  
   - Created new variables like `TotalPrice`.  
   - Processed date features for Recency calculations.  

3. **RFM Segmentation 🧩**  
   - Recency (🕒): How recently a customer purchased.  
   - Frequency (🔁): How often they purchase.  
   - Monetary (💰): Total spending.  
   - Customers grouped into **Champions, Loyal, At-Risk, Lost/Hibernating, etc.**  

4. **Visualizations 📊**  
   - Distribution plots (Recency, Frequency, Monetary)  
   - Average Monetary per Segment (Bar Chart)  
   - Frequency vs. Monetary Scatter Plot  
   - Boxplots with Colored Bubbles 🎨  
   - KMeans Clustering Visualization 🤖  

5. **Marketing Insights 🎯**  
   - Loyalty rewards for Champions 🏆  
   - Targeted discounts 🎟️ for repeat buyers  
   - Re-engagement campaigns ✉️ for at-risk/lost customers
